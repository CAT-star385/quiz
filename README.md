# 🎯 字義測驗 Chinese Vocabulary Quiz

> 免費的中文字義線上測驗工具,適合台灣國小、國中學生練習詞語意思,以及老師班級小考使用。
> A free online Chinese vocabulary quiz for Taiwanese students (zh-TW).

🔗 **線上使用 / Try it now:** **https://cat-star385.github.io/quiz/quiz.html**

---

## ✨ 特色 Features

- 📖 **三種題型**
  - 看詞選意思(顯示詞語,選正確解釋)
  - 看意思選字(顯示解釋,選對應詞語)
  - 綜合測驗(兩種隨機混合)
- 📚 **內建多套題庫** — 預設、四字成語、形容詞,共 90+ 題
- ✏️ **自訂題庫** — 輸入「詞語|詞性|意思」格式即可
- 👩‍🏫 **老師出題模式** — 產生專屬連結傳給學生,點開直接考試
- 🎯 **錯題重考** — 結束後可只重考答錯的題目
- 🧠 **智慧干擾項** — 自動產生「容易混淆」的選項(共用字、同字數、同詞性優先)
- ⏱ **考試計時** — 30 秒 / 1 分 / 3 分 / 5 分,時間到自動交卷
- ➕ **+30 秒延長** — 考試中可隨時延長時間
- 🌙 **深色模式**
- 🔤 **字體大小調整**

## 🚀 怎麼使用

1. 打開網址 → https://cat-star385.github.io/quiz/quiz.html
2. 選題型(看詞選意思 / 看意思選字 / 綜合)
3. 選題庫(內建或自訂)

5. 開始 → 完成 → 看結果 → 可只重考錯題

## 📝 自訂題庫格式

每行一個詞語,用 `|` 分隔欄位:

```
詞語|詞性|意思
勤勞|形|認真努力做事
謙虛|形|不自滿、不誇大
舉一反三|動|從一件事推知其他類似的事
```

也可省略詞性:`勤勞|認真努力做事`

至少需要 4 個詞才能產生 4 選 1 題目。
